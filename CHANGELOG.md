# Changelog

## 0.2.0 — Initial experimental public release

Prepared 2026-11-14. Intended tag: [`native-operator-interaction-v0.2.0`](https://github.com/Hanukashats/Schatztruhe/releases/tag/native-operator-interaction-v0.2.0). This entry describes release contents; publication availability must be checked separately. No prior public release history is claimed.

### Included

- Schatztruhe collection identity, with one featured portable skill: Native Operator Interaction.
- Outcome-first explanations, evidence boundaries, causal diagrams, bounded analogies, and optional offline HTML reports.
- Focused references for explanations, reports, HTML, delivery, evaluation, and optional video.
- A standalone Russian-language interactive example with fictional data, static explanation, an adjustable illustrative model, evidence sections, and a draft-message selector. Its HTML is unchanged from the reviewed preparatory package.
- English and Russian overviews, manual installation and rollback, research sources, and provenance.
- MIT license at collection and skill-folder level, plus `license: MIT` and version `0.2.0` in skill metadata.
- Static package checks covering local documentation links, license preservation, metadata, and HTML structure; a `.gitignore` for caches and sensitive local files.

### Evidence limits

- Cursor, Codex, and Claude Code discovery conventions are documented; end-to-end runtime compatibility for this release is **UNTESTED**.
- Human understanding, decision quality, speed, and superiority over other methods are **not established**.
- Accessibility requirements are design and evaluation targets, not a claim of full conformance.
- Static tests do not replace browser testing, real client invocation, independent review, or evaluation with readers.
- Conceptual source comparisons do not imply adoption of donor code, assets, renderers, transcript importers, or dependencies.
